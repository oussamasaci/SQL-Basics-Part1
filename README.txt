TRAILPEAK SQL FOUNDATIONS 1 PRACTICE BUNDLE -- By Oussama Saci
Business scenario and data are generated using AI.

Contents
- SQL_Foundations_1_TrailPeak_Assignment.docx: scaffolded student assignment and deliverables checklist.
- trailpeak_setup.sql: PostgreSQL script that creates and populates three practice tables.
- csv/: the same synthetic data as three CSV files for inspection/reference.

Getting started
1. Open your PostgreSQL practice database in pgAdmin or another SQL client.
2. Open and run trailpeak_setup.sql. WARNING: it drops and recreates the three tables named in the script. Use a dedicated practice database.
3. Follow Step 0 of the assignment, then write your own queries in student_submission.sql.

Table sizes
- trailpeak_staff: 25 rows
- trailpeak_rentals: 28 rows
- trailpeak_inspections: 25 rows

Dialect: PostgreSQL. All data is synthetic. Currency values are DZD.
